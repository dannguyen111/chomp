# C0012

**Claim.** For all integers `q >= r >= 0`, `f(q,r) <= q + r + 1`.

**Corollary.** `max_{q >= r} (f(q,r) - q) <= r + 1`.

---

## Setup

`f` is defined on pairs of non-negative integers by

```
  f(0,0) = 1
  f(q,r) = f(q,q)                                       if r > q                (A)
  f(q,r) = f(q-1,r)                                     if q >= 1 and f(q-1,r) < q   (B)
  f(q,r) = mex( {f(a,r) : a < q} u {f(q,b) : b < r} )   otherwise                (C)
```

where `mex(S)` is the least **positive** integer not in `S`.

**The recursion is well founded under the lexicographic order on `(q,r)`.**
Branch (A) reads `f(q,q)` and `q < r`, so `(q,q) <_lex (q,r)`. Branch (B) reads
`f(q-1,r)` with `q-1 < q`. Branch (C) reads `f(a,r)` with `a < q`, and `f(q,b)`
with `b < r`. Every read is at a strictly earlier pair, so induction over
`<_lex` is available.

We prove the following slightly larger statement, which covers the pairs with
`r > q` that branch (A) needs:

> **(P)** for all `q, r >= 0`, `f(q,r) <= q + min(q,r) + 1`.

(P) implies the claim: when `r <= q`, `min(q,r) = r`.

## Proof of (P)

By induction over `<_lex`. Let `(q,r)` be given and assume (P) at every
lexicographically earlier pair.

**Base, `(q,r) = (0,0)`.** `f(0,0) = 1 = 0 + min(0,0) + 1`.

**Branch (A), `r > q`.** Here `min(q,r) = q`, and `(q,q) <_lex (q,r)`, so by the
induction hypothesis
`f(q,r) = f(q,q) <= q + min(q,q) + 1 = 2q + 1 = q + min(q,r) + 1`.

**Branch (B), `q >= 1` and `f(q-1,r) < q`.** The branch condition alone gives
the bound, with no appeal to the induction hypothesis:
`f(q,r) = f(q-1,r) < q <= q + min(q,r) + 1`, since `min(q,r) >= 0`.

**Branch (C).** Write `S = {f(a,r) : 0 <= a < q} u {f(q,b) : 0 <= b < r}`, so
that `f(q,r) = mex(S)`. The first set has at most `q` elements and the second at
most `r`, hence

```
  |S| <= q + r.
```

Consider the `q + r + 1` positive integers `1, 2, ..., q + r + 1`. At most `|S|
<= q + r` of them lie in `S`, so at least one does not. The least positive
integer outside `S` is therefore at most `q + r + 1`:

```
  f(q,r) = mex(S) <= q + r + 1.
```

Branch (C) is only reached when `r <= q` -- a pair with `r > q` is caught by (A)
-- so `min(q,r) = r` here and the displayed bound is exactly
`q + min(q,r) + 1`. []

**Note on what the argument uses.** Branch (C) needs only the *cardinality* of
`S`. It does not use the induction hypothesis on the values in `S`, nor any
property of `f` beyond the shape of the recurrence. In particular the bound
would hold for any function defined by the same mex recursion over the same
index sets.

## Corollary

For `q >= r`, (P) gives `f(q,r) - q <= r + 1`, and the right-hand side does not
depend on `q`. Hence `max_{q >= r} (f(q,r) - q) <= r + 1`.

## Numerical check

Independent of the proof, the bound was checked against the solver:

- every cell of the table with `q, r <= 400`: **0 violations**;
- every live row's eventual `p - q` values for `r <= 50000` (20711 rows):
  **0 violations**;
- the bound is attained (`f(q,r) = q + r + 1`) at 402 cells with `q, r <= 400`,
  all of them on the row `r = 0`, where `f(q,0) = q + 1` exactly. So it is
  tight, and no constant smaller than `1` can replace the `+1`.

The corollary is loose by roughly a factor of `sqrt(2)`: the observed maximum of
`f(q,r) - q` over `q` grows like `r / sqrt(2) ~ 0.7071 r`, against the proved
bound `r + 1`.
