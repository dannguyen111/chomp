**Claim.** For all integers `q >= r >= 0`, `f(q,r) <= q + r + 1`.

**Corollary.** `max_{q >= r} (f(q,r) - q) <= r + 1`.

---

## Setup

`f` is defined on pairs of non-negative integers by

```
  f(0,0) = 1
  f(q,r) = f(q,q)                                       if r > q                (A)
  f(q,r) = f(q-1,r)                                     if q >= 1 and f(q-1,r) < q   (B)
  f(q,r) = mex( {f(a,r) : a < q} u {f(q,b) : b < r} )   otherwise                (C)
```

where `mex(S)` is the least **positive** integer not in `S`.

**The recursion is well founded under the lexicographic order on `(q,r)`.**
Branch (A) reads `f(q,q)` and `q < r`, so `(q,q) <_lex (q,r)`. Branch (B) reads
`f(q-1,r)` with `q-1 < q`. Branch (C) reads `f(a,r)` with `a < q`, and `f(q,b)`
with `b < r`. Every read is at a strictly earlier pair, so induction over
`<_lex` is available.

We prove the following slightly larger statement, which covers the pairs with
`r > q` that branch (A) needs:

> **(P)** for all `q, r >= 0`, `f(q,r) <= q + min(q,r) + 1`.

(P) implies the claim: when `r <= q`, `min(q,r) = r`.

## Proof of (P)

By induction over `<_lex`. Let `(q,r)` be given and assume (P) at every
lexicographically earlier pair.

**Base, `(q,r) = (0,0)`.** `f(0,0) = 1 = 0 + min(0,0) + 1`.

**Branch (A), `r > q`.** Here `min(q,r) = q`, and `(q,q) <_lex (q,r)`, so by the
induction hypothesis
`f(q,r) = f(q,q) <= q + min(q,q) + 1 = 2q + 1 = q + min(q,r) + 1`.

**Branch (B), `q >= 1` and `f(q-1,r) < q`.** The branch condition alone gives
the bound, with no appeal to the induction hypothesis:
`f(q,r) = f(q-1,r) < q <= q + min(q,r) + 1`, since `min(q,r) >= 0`.

**Branch (C).** Write `S = {f(a,r) : 0 <= a < q} u {f(q,b) : 0 <= b < r}`, so
that `f(q,r) = mex(S)`. The first set has at most `q` elements and the second at
most `r`, hence

```
  |S| <= q + r.
```

Consider the `q + r + 1` positive integers `1, 2, ..., q + r + 1`. At most `|S|
<= q + r` of them lie in `S`, so at least one does not. The least positive
integer outside `S` is therefore at most `q + r + 1`:

```
  f(q,r) = mex(S) <= q + r + 1.
```

Branch (C) is only reached when `r <= q` -- a pair with `r > q` is caught by (A)
-- so `min(q,r) = r` here and the displayed bound is exactly
`q + min(q,r) + 1`. []

**Note on what the argument uses.** Branch (C) needs only the *cardinality* of
`S`. It does not use the induction hypothesis on the values in `S`, nor any
property of `f` beyond the shape of the recurrence. In particular the bound
would hold for any function defined by the same mex recursion over the same
index sets.

## The matching lower bound is in the literature

The bound above is an upper bound obtained by *counting* `S`. The complementary
lower bound comes from `S` being **distinct**, and is due to Sheiner
(arXiv:2605.23837, 2026):

> **Lemma 2.3(a).** For fixed `q`, the values `f(q,0), f(q,1), ..., f(q,q)` are
> distinct.
>
> **Lemma 4.1.** `f(q,q) = max_{0 <= r <= q} f(q,r)`; in particular `f(q,q) > q`.

His `> q` is the same counting move run the other way: `q+1` distinct positive
integers force a maximum of at least `q+1`. So the diagonal satisfies

```
  q + 1  <=  f(q,q)  <=  2q + 1,
```

the left from distinctness (Sheiner), the right from (P) above. Lemma 4.1 is
also Brouwer's section 8.3 ("diagonal elements are largest in their column",
#G07) supplied with a proof.

Neither this file nor #G07 needs the lower bound, but anyone extending the
counting argument should know that the distinctness half is already proved, and
that it is the half that does real work in the literature.

Checked against the solver over every `q <= 400`: **0 violations** of
`q + 1 <= f(q,q) <= 2q + 1`, with the lower end attained once and the upper end
twice, so neither side can be improved by a constant. The same sweep confirms
Sheiner's two lemmas independently -- **0 violations** of distinctness down a
column, and **0** of the diagonal being the column maximum.

## Corollary

For `q >= r`, (P) gives `f(q,r) - q <= r + 1`, and the right-hand side does not
depend on `q`. Hence `max_{q >= r} (f(q,r) - q) <= r + 1`.

**What the corollary is, and is not, good for.** It supplies one input to a
later argument, namely an explicit `C` with `max_q (f(q,r) - q) <= C r` for all
`r >= 1` (here `C = 2` suffices, since `r + 1 <= 2r`). That quantity bounds the
*values* of `f(q,r) - q`. It is **not** a bound on the preperiod: the least
`q0` beyond which `f(q,r) - q` is exactly periodic in `q` is a different
quantity, and bounded values do not by themselves bound it, since a bounded
sequence need not become periodic quickly. Any use of this lemma toward a
preperiod bound needs a separate argument supplying the state count, and that
argument is not in this file.

## Numerical check

Independent of the proof, the bound was checked against the solver:

- every cell of the table with `q, r <= 400`: **0 violations**;
- every live row's eventual `p - q` values for `1 <= r <= 50000` (20711 rows):
  **0 violations**. Counting from `r = 0` instead gives 20712, since the
  degenerate row `r = 0` is live with constant `d = 1`; the range convention
  throughout this project is `r >= 1`. The worst ratio `d / (r+1)` is `1.0`,
  attained only at `r = 0`, and at most about `0.67` for every `r >= 2`;
- the bound is attained (`f(q,r) = q + r + 1`) at exactly 402 cells with
  `q, r <= 400`: the 401 cells of the row `r = 0`, where `f(q,0) = q + 1`
  exactly, **and the single cell `(q,r) = (1,1)`**, where `f(1,1) = 3`. On any
  grid `q, r <= Q` the tight set is the row `r = 0` together with `(1,1)`.
  So the bound is tight, and no constant smaller than `1` can replace the `+1`.

  *(Corrected 2026-09-21: an earlier version of this file said all 402 tight
  cells lay on the row `r = 0`. The count was right, the attribution was not.)*

The corollary is loose by roughly a factor of `sqrt(2)`: the observed maximum of
`f(q,r) - q` over `q` grows like `r / sqrt(2) ~ 0.7071 r`, against the proved
bound `r + 1`.
