# C0021

**Claim.** For every P-position `(p,q,r)` of 3-row Chomp with `r >= 1`,

```
    p - q  <=  3r - 1,
```

uniformly in `q`. Equivalently `max_{q >= r} (f(q,r) - q) <= 3r - 1`.

This is Byrnes' Lemma 5 specialised to 3-row Chomp with the third row fixed.
The content below is the specialisation -- the embedding -- not a new argument.

---

## What Lemma 5 says

Byrnes, *Poset-Game Periodicity*, p.8:

> **Lemma 5.** If `g(A_{m,n}) = k`, then `n - m <= |A| + k`. Also, if
> `k not in Q(A)`, or if `c_{m+1} > d_{n+1}`, then `|n - m| <= |A| + k`.

The first clause is unconditional. We use it with `k = 0`, so that
`g(A_{m,n}) = 0` means `A_{m,n}` is a P-position.

## The setting

Byrnes assumes (his (1), p.6) an infinite poset `X` containing two infinite
chains `C = {c_1 < c_2 < ...}`, `D = {d_1 < d_2 < ...}` and a finite set `A`,
all pairwise disjoint, such that **no element of `C` is less than an element of
`D`**; and defines

```
    A_{m,n} = A u C u D - {x in X : x >= c_{m+1}} - {x in X : x >= d_{n+1}}.
```

3-row Chomp is the poset of cells `(i,j)`, `1 <= i <= 3`, `j >= 1`, minus the
poisoned cell `(1,1)`, ordered componentwise: `(i,j) <= (i',j')` iff `i <= i'`
and `j <= j'`. Chomping `x` removes `{y : y >= x}`. Write a position as
`(p,q,r)` = the lengths of rows 1, 2, 3, with `p >= q >= r`.

## The embedding, with the third row fixed at r

Take

```
    A = { (i,j) : 1 <= i <= 3, 1 <= j <= r }  \  {(1,1)},     so |A| = 3r - 1
    C = { (2, r+1), (2, r+2), ... }            (the row-2 tail)
    D = { (1, r+1), (1, r+2), ... }            (the row-1 tail)
```

**This assignment is forced.** Assumption (1) requires no `c in C` below any
`d in D`. With `C` the row-2 tail and `D` the row-1 tail, `c = (2, r+j)` and
`d = (1, r+k)` give `c <= d` only if `2 <= 1`, which fails, so the condition
holds. With the roles swapped, `c = (1, r+j) <= d = (2, r+k)` whenever
`j <= k`, and (1) fails. So `C` is the row-2 tail and `D` is the row-1 tail,
and there is no freedom.

Now compute `A_{m,n}` with `c_{m+1} = (2, r+m+1)` and `d_{n+1} = (1, r+n+1)`:

- removing `{x >= c_{m+1}}` deletes every cell with `i >= 2` and
  `j >= r+m+1`, capping row 2 and row 3 at `r+m`. Row 3 is already `r <= r+m`,
  so only row 2 is affected;
- removing `{x >= d_{n+1}}` deletes every cell with `j >= r+n+1` in **all
  three** rows, capping row 1 at `r+n` and row 2 at `min(r+m, r+n)`.

Hence

```
    A_{m,n}  =  ( row1 = r+n,  row2 = r+min(m,n),  row3 = r ),
```

that is, taking `n >= m` so that `p >= q`,

```
    m = q - r          and          n = p - r.
```

## The bound

Let `(p,q,r)` be a P-position with third row `r`. Then `g(A_{m,n}) = 0` with
`m = q-r`, `n = p-r`, and Lemma 5 with `k = 0` gives

```
    n - m  =  (p - r) - (q - r)  =  p - q  <=  |A|  =  3r - 1.        []
```

The `r` cancels: **the bound is uniform in `q`.**

## Why the coordinate matters

Reading `n` as `p - q` instead of `p - r` yields
`(p-q) - (q-r) <= 3r - 1`, which is *true* -- it is weaker, since `q >= r` makes
`(p-q)-(q-r) <= p-q` -- but it is not what Lemma 5 gives, and it carries a
spurious `(q-r)` term that grows with `q`. That artefact makes the bound look
as though it degrades away from the diagonal and leaves something to prove for
large `q`. Under the correct coordinate there is nothing left to prove.

## Numerical check

Over every P-position with `q, r <= 2000` (computed by the validated solver):

- `p - q <= 3r - 1`: **0 violations**;
- equality holds at exactly one position, `(p,q,r) = (3,1,1)`, where both sides
  are `2`;
- the bound is loose by a factor tending to about `4.2`: the observed
  `max_q (p-q)` is `0.7071 r + O(1)`, against `3r - 1`, so the ratio
  `max(p-q)/(3r-1)` falls to `0.236 ~ 1/(3 sqrt(2))`.

A crude explicit constant is all that is needed downstream, so the looseness
does not matter.
