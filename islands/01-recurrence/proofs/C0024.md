# C0024 — the corrected effective Zeilberger recursion (proof)

**Claim.** For every `r >= 1` define

```
  B_c(a) := f(c+a, c) - (c+a)          (unique loser b at [c, a, .]; undefined if none)
  u_c    := N(c) - c                    (preperiod of B_c in a-coordinates)
  p_c    := period(c);  p_c := 1 for stale rows (B_c terminates)
  q_r    := lcm{ p_c : 0 <= c < r }
  m_r    := 1 + max{ B_c(a) : 0 <= c < r, a >= 0 }        (+1; max over defined values)
  U_r    := max{ u_c : 0 <= c < r }
  t_r    := max(U_r, r)
```

Then for every `r >= 1`:

```
  (i)  B_r(a) <= r      for every defined value (so    m_r <= r + 1),
  (ii) p_r <= q_r (m_r + 1)^{m_r},
  (iii) u_r <= max(t_r, m_r) + q_r (m_r + 1)^{m_r},
  (iv) q_{r+1} <= q_r^2 (r + 2)^{r + 1}.
```

In particular for live rows
`N(r) = r + u_r <= r + max(t_r, m_r) + q_r (m_r+1)^{m_r}`, while for stale rows
the last P-position `(p,q,r)` satisfies
`q - r <= max(t_r, m_r) + q_r (m_r+1)^{m_r}`, hence
`N(r) <= r + 1 + max(t_r, m_r) + q_r (m_r+1)^{m_r}`.

(i) is the value bound of C0012/C0021 (`f(q,r)-q <= r+1` in these coordinates);
(ii)-(iv) are the Ultimate-Periodicity Theorem of Zeilberger with the period
and preperiod of the instant-winner sequence made explicit. Nothing in the
argument is non-effective.

## 0. Coordinates and normalisations

Zeilberger's `[c, a, b]` has `c` columns of height 3, `a` of height 2, `b` of
height 1, so for the position `(p,q,r)`:

```
    c = r,   a = q - r,   b = p - q.
```

`B_c(a)` is the unique `b` such that `[c,a,b]` is a loser (uniqueness is the
first family of Zeilberger's `(Rule1)`); if none exists `B_c(a)` is undefined.
Hence `B_r(a) = f(r+a, r) - (r+a)`, and the census quantity
`d(q) = f(q,r) - q` equals `B_r(q - r)` wherever a genuine P-position exists
(`f(q,r) >= q`; for live rows this is every `q >= r`).

**Preperiod in `a`.** `N(r)` is the least `q0` such that `d(q)` is
`p_r`-periodic for all `q >= q0`. Under `q = r + a` this is: `B_r(a)` is
`p_r`-periodic for all `a >= N(r) - r =: u_r`. Minimality of `q0` translates
to: `B_r(u_r - 1) != B_r(u_r - 1 + p_r)` when `u_r >= 1` (live rows).

**Stale rows.** A stale row has finitely many P-positions; the last has
`f(q*, r) = q*`, i.e. `B_r(a*) = 0` at `a* = q* - r`, and no values for
`a > a*`. The census carries `N(r) = lastlive + 1`, so `a* = N(r) - 1 - r =
u_r - 1` and `u_r = N(r) - r` is uniform. Setting `p_r := 1`, the statement
"`B_r` is `p_r`-periodic from `a = u_r`" holds vacuously (no values are defined
for `a >= u_r`).

## 1. The instant-winner sequence and its preperiod

Fix the bottom row at `r`. The losers `[c, a', b']` with `c < r` force, through
Zeilberger's Lemmas 1-3, a set `W_r(a)` of "instant winners" — the `b` such
that `[r, a, b]` is a winner implied by some game below row `r`. His Crucial
Facts give `W_r(a)` explicitly as a union of singletons:

```
    V''_{r,c}(a) = { B_c(a + r - c) }                        (from (1.3),(2.2))
    V'_{r,c}(a)  = { B_c(0) - (r-c) - a }  ∩  Z_{>=0}        (from Lemma 3)
    W_r(a)       = ⋃_{c<r} ( V''_{r,c}(a) ∪ V'_{r,c}(a) ),
```

with empty singletons discarded.

**Lemma P (period of W).** `W_r` is `q_r`-periodic for all `a >= t_r`, where
`t_r = max(U_r, r)`.

*Proof.*

- *The V'' family.* For `a >= U_r` and `c < r`, the index of the `B_c`
  evaluation is `a'' := a + r - c >= U_r + (r-c) >= u_c + 1`, using
  `r - c >= 1`. Two cases. If `c` is live, `B_c(a'')` is defined for all
  `a'' >= 0` and is `p_c`-periodic on `a'' >= u_c`. If `c` is stale, `B_c` is
  defined for `a'' <= u_c - 1` only, so for `a'' >= u_c + 1` the value is
  undefined and the singleton is empty. In both cases, on `a >= U_r` the map
  `a ↦ V''_{r,c}(a)` is `p_c`-periodic in `a` (defined values periodic; the
  stale rows are empty, hence constant). Since `p_c | q_r`, it is
  `q_r`-periodic.

- *The V' family.* For `a >= r`, `V'_{r,c}(a)` is empty for every `c < r`:
  the value is `B_c(0) - (r-c) - a <= (c+1) - (r-c) - r = 2c + 1 - 2r < 0`,
  where `B_c(0) = f(c,c) - c <= c + 1` is C0012 applied at the diagonal, and
  `c <= r - 1`. So on `a >= r` the V' contribution is the constant empty set.

Both families are `q_r`-periodic on `a >= max(U_r, r) = t_r`, and the union is
too. ∎

*Remark.* This is the piece C0023 was missing: not Zeilberger's bare assertion
that "the sequence `I_a` is ultimately-periodic", but the explicit values of
its period `q_r` and preperiod `t_r`.

## 2. Boundedness: (i)

By C0012 (prior art, cited), `B_c(a) = f(c+a,c) - (c+a) <= c+1` for every
defined value, and `c < r` gives `<= r`. Hence `m_r <= r + 1`, proving (i).

Zeilberger's Lemma Bounded then applies with `M = m_r`: every defined
`B_r(a) <= m_r` while the sequence has not terminated. In particular `L_a =
B_r(a) <= m_r` in the region where the finite-memory recurrence below runs.

## 3. The finite-memory recurrence and the state

For `a` at which `L_a` is defined and positive, Zeilberger's Fundamental
Recurrence (a mex over the *non-negative* integers, matching `b = p-q >= 0`)

```
    L_a = mex( W_r(a)  ∪  { L_{a-1}-1, L_{a-2}-2, ..., L_0 - a } )
```

holds identically; verified numerically against the solver (F3 below). Since
`L_{a-i} <= M = m_r` for every `i < a`, a term `L_{a-i} - i` is non-negative
only for `i <= M - 1`, and the smallest dropped term (at `i = M+1`) is
`<= M - (M+1) = -1 < 0`. Hence the recurrence is equivalent to the finite-memory
form

```
    L_a = mex( W_r(a)  ∪  { L_{a-1}-1, ..., L_{a-M}-M } ),        M = m_r
```

where `M` trailing values `L_{a-1}, ..., L_{a-M}` lie in `[0, M]`.

**The state must carry the phase.** The recurrence's next instant-winner set
`W_r(a+1)` is a function of the index `a+1`, and — here unlike a fully
stored sequence — `W_r` enters only through its `q_r`-periodic tail. So the
correct finite state is

```
    S_a = ( a mod q_r ;  L_{a-1}, L_{a-2}, ..., L_{a-M} ).
```

(Equivalently `(W_r(a); L_{a-1},...,L_{a-M})` *together with* the phase; the
phase determines `W_r(a)` since `W_r` is `q_r`-periodic on `a >= t_r`, so the
phase form is minimal.) On `a >= max(t_r, m_r)` the transition

```
    F : (τ; L_{a-1},...,L_{a-M}) ↦ (τ+1 mod q_r; L_a, L_{a-1},...,L_{a-M+1})
```

with `L_a = mex( W_r(τ) ∪ {L_{a-1}-1, ..., L_{a-M}-M} )` is a well-defined
deterministic function of the state alone: `W_r(τ)` is the one periodic value
at phase `τ`, and `L_{a-M+1}` is the value dropped from the trail. Omitting the
phase would leave `W_r(a+1)` undetermined by the state; with the phase it is
not. The number of states is at most

```
    q_r · (M + 1)^M  =  q_r (m_r + 1)^{m_r}.
```

## 4. Pigeonhole: (ii) and (iii)

Set `A0 := max(t_r, m_r)`. From `a = A0` the map `F` is a deterministic
function on a set of size at most `S := q_r(m_r+1)^{m_r}`. Among the `S + 1`
indices `A0, A0+1, ..., A0 + S` two states coincide: `S_{a1} = S_{a2}`,
`A0 <= a1 < a2 <= A0 + S`. Since `F` is deterministic from `A0` on, the entire
future repeats with period `s := a2 - a1` from `a1` on; in particular `L_a` is
`s`-periodic for `a >= a1`, and `s` is a multiple of `q_r` (the phases match),
so `s | q_r`-compatible, with `s <= S`. Therefore

```
    p_r <= s <= q_r (m_r+1)^{m_r}                                    (ii)
    u_r <= a1 <= A0 + s = max(t_r, m_r) + q_r (m_r+1)^{m_r}         (iii)
```

(Here `p_r` divides `s` since `s` is *a* period, and `u_r` is the least
preperiod, hence `<= a1`.)

For a **stale** row the sequence terminates: `L_{a*} = 0` at some `a*` and no
value for `a > a*`. If `a* > A0 + S`, the pigeonhole over `A0..A0+S` would
already have produced a repeated state strictly before termination, forcing `L`
to stay periodic (hence defined and `> 0`) past `a*` — a contradiction. Hence
`a* = u_r - 1 <= A0 + S`, giving the stale bound displayed. ∎

For (iv): `q_{r+1} = lcm(q_r, p_r) <= q_r · p_r <= q_r^2 (m_r+1)^{m_r}`, and
`m_r + 1 <= r + 2`, `m_r <= r + 1`, give `q_{r+1} <= q_r^2 (r+2)^{r+1}`. ∎

## Numerical verification

`islands/01-recurrence/scratch/verify_recursion.py` checks, for every
`r <= 400` and `a <= 1400`, against the validated solver:

- **F1**: the translation `B_r(a) = f(r+a,r)-(r+a)` matches the census `d`
  values exactly (definedness included);
- **F2**: `B_r(a)` is `p_r`-periodic for `a >= u_r`, and not for `a = u_r - 1`;
- **F3**: the Fundamental Recurrence driven by `W_r` reproduces `B_r(a)`,
  including the stale rows up to and including their terminating `0`;
- **F4**: `W_r` is `q_r`-periodic for `a >= t_r` (actual preperiod never
  exceeds `t_r`; bound slack up to 117, i.e. safe);
- **F5**: `m_r <= r + 1`, `p_r <= q_r (m_r+1)^{m_r}`, and
  `u_r <= max(t_r, m_r) + q_r (m_r+1)^{m_r}`, for live and stale rows alike;
  worst ratios `p_r/bound = 0.0156`, `u_r/bound = 0.0448`.

The only inequality carrying structure on the data is (i), which is the cited
prior-art bound; (ii)-(iv) are counting arguments whose sole failure mode is a
coordinate slip, which F1-F5 collectively pin down.

## What this does and does not claim

It claims (ii)-(iv): a **recursion** that bounds `N(r)` in terms of the solved
rows `c < r` and the explicit constant `r+1`. This is the repair of C0013 that
C0023 demanded (the preperiod `t_r` is folded in, and the closed form in C0013
is *not* asserted here). It is **not** a closed form: `q_r` is defined by the
recursion, not by an a priori formula; a closed form needs (Z2), a bound on
`lcm{period(c) : c < r}`, which is a separate open question and not supplied.

For **effectivity alone** this recursion is complete: each `q_r, m_r, t_r` is a
finite computation over rows `c < r`, and the argument shows the
pigeonhole-bound always dominates the true `N(r)`. (This is the programme of
C0022; here it is carried out with the constants pinned.)
