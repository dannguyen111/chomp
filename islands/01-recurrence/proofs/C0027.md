# A closed-form a priori bound on the preperiod N(r) for 3-row Chomp

**Claim.** Let `f(q,r)` be the unique `p` such that `(p,q,r)` is a P-position of
3-row Chomp, defined by the Brouwer recurrence; for each fixed `r`, let `N(r)`
be the least `q0` such that `f(q,r)-q` is eventually periodic in `q` for all
`q >= q0`. Then there is an explicit, computable, closed-form bound
`N(r) <= r + h(r)` with `h` given below by a finite sum of explicit terms; no
quantity on the right is defined by a recursion over the actual rows.

---

## 0. Standing inputs (stated here, used as black boxes)

**Input 1 (value bound, prior art).** For all `q >= r >= 0`,
`f(q,r) <= q + r + 1`. Equivalently, in Zeilberger coordinates
`[c,a,b] = [r, q-r, p-q]` with `B_c(a) = f(c+a,c)-(c+a)`, every defined value
satisfies `B_c(a) <= c + 1`.

**Input 2 (finite-state recursion).** With

```
  u_c = N(c) - c,
  p_c = period of B_c in a   (p_c := 1 if B_c terminates),
  q_r = lcm{ p_c : 0 <= c < r },
  m_r = 1 + max{ B_c(a) : 0 <= c < r, a >= 0 },
  t_r = max( max_{c<r} u_c, r ),
```

one has, for every `r >= 1`:

```
  (i)  m_r <= r + 1,
  (ii) p_r <= q_r (m_r + 1)^{m_r},
  (iii) u_r <= max(t_r, m_r) + q_r (m_r + 1)^{m_r}       (live rows), and
        u_r <= 1 + max(t_r, m_r) + q_r (m_r + 1)^{m_r}   (stale rows),
  (iv) q_{r+1} <= q_r^2 (r + 2)^{r + 1}.
```

Input 1 is a four-line induction on the three branches of the Brouwer
recurrence (the mex branch takes a mex over at most `q+r` positive integers, so
one of `1..q+r+1` is missing). Input 2 is the finite-state pigeonhole for
Zeilberger's three-row proof, with the instant-winner preperiod made explicit:
the state `(a mod q_r; L_{a-1},...,L_{a-m_r})` is deterministic from
`a >= max(t_r, m_r)`, there are at most `q_r (m_r+1)^{m_r}` states, and the
pigeonhole gives (ii) and (iii); (iv) is `q_{r+1} = lcm(q_r, p_r) <= q_r p_r`
combined with (ii).

## 1. The unrolling: (iv) is an a priori lcm bound

Define the a priori sequence `g` (no solver, no recursion over solved rows):

```
  g(1) = 1,      g(r+1) = g(r)^2 · (r+2)^{r+1}.
```

**Lemma A (a priori lcm bound).** `q_r <= g(r)` for every `r >= 1`.

*Proof.* Row `0` has period `p_0 = 1`, so `q_1 = 1 = g(1)`. Inductively,

```
  q_{r+1} = lcm(q_r, p_r) <= q_r · p_r
          <= q_r · [ q_r (m_r+1)^{m_r} ]                    (by (ii))
          <= g(r) · [ g(r) (r+2)^{r+1} ]                    (by (i), ind. hyp.)
          =  g(r)^2 (r+2)^{r+1}  =  g(r+1).                 ∎
```

The step `(m_r+1)^{m_r} <= (r+2)^{r+1}` uses (i): `m_r <= r+1`, and the map
`m -> (m+1)^m` is increasing on `m >= 1`. Hence `q_r` is bounded by an explicit
function of `r` alone.

## 2. The preperiod bound unrolls too

Define the a priori sequence `h` by

```
  h(1) = 12,
  h(r) = 1 + h(r-1) + g(r) (r+2)^{r+1}        (r >= 2).
```

**Lemma B (a priori preperiod bound).** `u_r = N(r) - r <= h(r)` for every
`r >= 1`, and consequently `N(r) <= r + h(r)` for all rows (live and stale).

*Proof.* Induction on `r`. Base `r = 1`: `u_1 = N(1)-1 = 3-1 = 2 <= 12 = h(1)`.

For the step, both cases of (iii) give the common bound

```
  u_r <= 1 + max(t_r, m_r) + q_r (m_r+1)^{m_r}.              (*)
```

By induction `u_c <= h(c)` for `c < r`, and `h` is increasing, so
`max_{c<r} u_c <= h(r-1)`; hence `t_r = max(max_{c<r} u_c, r) <= max(h(r-1), r)`.
Also `m_r <= r+1` by (i) and `q_r <= g(r)` by Lemma A. Substituting into (*):

```
  u_r <= 1 + max(h(r-1), r, r+1) + g(r) (r+2)^{r+1}.
```

Since `h` is increasing with `h(1) = 12`, we have `h(r-1) >= 12 > r+1 >= r` for
all `r >= 2`, so `max(h(r-1), r, r+1) = h(r-1)` and

```
  u_r <= 1 + h(r-1) + g(r) (r+2)^{r+1} = h(r).               ∎
```

## 3. The closed form

`g` has the explicit closed form: with `L(r) = log_2 g(r)`,

```
  L(1) = 0,   L(r+1) = 2 L(r) + (r+1) log_2(r+2),
  L(r) = sum_{k=1}^{r-1} 2^{r-1-k} (k+1) log_2(k+2)  =  Theta(2^r),
```

so `g(r) = 2^{Theta(2^r)}`. Unrolling `h` gives the fully explicit finite sum

```
  h(r) = 11 + r + sum_{k=2}^{r} g(k) (k+2)^{k+1}.
```

Hence `h(r) = 2^{Theta(2^r)}` and the final bound is

```
  N(r)  <=  r + h(r)  <=  2^{2^{O(r)}}.
```

This is a double-exponential but fully explicit computable bound on the
preperiod `N(r)`. It is a genuine closed form: every quantity on the right is
an explicit function of `r` alone, not a recursion over the actual rows.

## 4. Numerical verification

An independent script checks the claim against the validated solver (the
recurrence of section 0, implemented in C++ and cross-checked against the
published tables):

- exact big-integer evaluation for `r <= 12` (`g(12) ~ 2^13057` is a ~4000-digit
  integer): `N(r) <= r + h(r)` holds for every row, live and stale, with
  enormous slack (the bound at `r = 12` is a ~3900-digit number against the
  true `N(12) = 18`);
- log-space evaluation for `r <= 60`: the same inequality holds throughout,
  with `log_2 h(r) ~ 2^r` confirmed.

## 5. What this does and does not claim

It claims a **closed-form computable bound** on `N(r)`, of the form
`N(r) <= 2^{2^{O(r)}}`, obtained by unrolling a finite-state pigeonhole plus a
value bound. It does **not** claim any improvement of the exponent or constant:
the bound is double-exponential where the truth is linear (`N(r) = sqrt(2) r +
O(1)` empirically). Sharpening to `C·r` is a separate and much deeper question
and is not addressed here.
