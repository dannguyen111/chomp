# A sharper closed-form bound on N(r): the lcm recursion is linear, not quadratic

**Claim.** Let `f(q,r)` be the unique `p` such that `(p,q,r)` is a P-position of
3-row Chomp (Brouwer recurrence); for each fixed `r`, let `N(r)` be the least
`q0 >= r` such that `f(q,r)-q` is periodic for all `q >= q0` (for a row with
only finitely many P-positions, `N(r)` is the least `q` with `f(q,r) < q`). Then

```
  N(r) <= r + h(r),    h(r) = 11 + r + sum_{k=2}^{r} g(k) (k+2)^{k+1},
  g(1) = 1,   g(r+1) = g(r) · (r+2)^{r+1},
```

so `g(r) = prod_{k=1}^{r-1} (k+2)^{k+1}` and

```
  log_2 g(r) = sum_{k=1}^{r-1} (k+1) log_2(k+2) = O(r^2 log r),
  N(r) <= 2^{O(r^2 log r)}.
```

This is an explicit, computable, closed-form bound; every quantity on the right
is a function of `r` alone. It is strictly sharper than the `2^{2^{O(r)}}`
bound obtained from the quadratic lcm recursion: the correct recursion is
**linear** in `q_r`, not quadratic.

---

## 0. Standing inputs (same as the companion proof; stated as black boxes)

**Input 1 (value bound, prior art).** For all `q >= r >= 0`,
`f(q,r) <= q + r + 1`. In Zeilberger coordinates `[c,a,b] = [r, q-r, p-q]` with
`B_c(a) = f(c+a,c)-(c+a)`, every defined value satisfies `B_c(a) <= c+1`.

**Input 2 (finite-state recursion).** With `u_c = N(c)-c`, `p_c` = the period of
`B_c` in `a` (`p_c := 1` if `B_c` terminates), `q_r = lcm{p_c : 0 <= c < r}`,
`m_r = 1 + max{B_c(a) : 0 <= c < r, a >= 0}`, `t_r = max(max_{c<r} u_c, r)`:

```
  (i)  m_r <= r + 1,
  (ii) p_r <= q_r (m_r + 1)^{m_r},
  (iii) u_r <= 1 + max(t_r, m_r) + q_r (m_r + 1)^{m_r}     (all rows),
```

and the state `S_a = (a mod q_r; L_{a-1}, ..., L_{a-m_r})` is deterministic from
`a >= max(t_r, m_r)`, with at most `q_r (m_r+1)^{m_r}` states.

## 1. The sharpened lcm bound (the one improvement over the companion proof)

The companion proof derived `q_{r+1} <= q_r^2 (r+2)^{r+1}` from
`q_{r+1} = lcm(q_r, p_r) <= q_r p_r` together with (ii). That loses a factor
`q_r` unnecessarily. The pigeonhole itself gives the sharper statement directly:

**Lemma A' (linear lcm recursion).** `q_{r+1} <= q_r (m_r + 1)^{m_r} <= q_r (r+2)^{r+1}`.

*Proof.* Run the C0024 pigeonhole from `a = A0 = max(t_r, m_r)`. Among the
`S + 1` consecutive states `S_{A0}, ..., S_{A0+S}`, where
`S = q_r (m_r+1)^{m_r}`, two coincide: `S_{a1} = S_{a2}` with
`A0 <= a1 < a2 <= A0 + S`. Because the state carries the phase `a mod q_r`,
`a1 ≡ a2 (mod q_r)`, so `s := a2 - a1` is a multiple of `q_r`. The transition
is deterministic from `A0` on, so the entire future repeats with period `s`:
`L_a = B_r(a)` is `s`-periodic for all `a >= a1`. Hence `s` is a period of the
(eventually periodic) row-`r` sequence, so the fundamental period divides it:
`p_r | s`. Therefore `s` is a common multiple of `q_r` and `p_r`, and

```
  q_{r+1} = lcm(q_r, p_r)  |  s  <=  S = q_r (m_r+1)^{m_r}.
```

The second inequality is (i): `m_r <= r+1`, and `m -> (m+1)^m` is increasing. ∎

The point: one does **not** need to multiply (ii)'s bound on `p_r` by `q_r`;
the pigeonhole produces a common multiple of `q_r` and `p_r` directly.

## 2. The unrolling

Define the a priori sequence `g` by the linear recursion:

```
  g(1) = 1,      g(r+1) = g(r) · (r+2)^{r+1}.
```

**Lemma B' (a priori lcm bound).** `q_r <= g(r)` for every `r >= 1`.

*Proof.* Row `0` has period 1, so `q_1 = 1 = g(1)`. Inductively, Lemma A' gives

```
  q_{r+1} <= q_r (r+2)^{r+1} <= g(r) (r+2)^{r+1} = g(r+1).   ∎
```

Define the a priori sequence `h` by

```
  h(1) = 12,      h(r) = 1 + h(r-1) + g(r) (r+2)^{r+1}   (r >= 2).
```

**Lemma C' (a priori preperiod bound).** `u_r = N(r) - r <= h(r)` for every
`r >= 1`, hence `N(r) <= r + h(r)` for all rows.

*Proof.* Identical to the companion proof: (iii) gives
`u_r <= 1 + max(t_r, m_r) + q_r(m_r+1)^{m_r}`; by induction `u_c <= h(c)` for
`c < r` and `h` is increasing, so `t_r <= max(h(r-1), r)`; `m_r <= r+1`; and
`q_r <= g(r)`. Since `h(r-1) >= 12 > r+1`, the max is `h(r-1)`, giving
`u_r <= 1 + h(r-1) + g(r)(r+2)^{r+1} = h(r)`. ∎

## 3. The closed form and its growth

```
  g(r) = prod_{k=1}^{r-1} (k+2)^{k+1},
  log_2 g(r) = sum_{k=1}^{r-1} (k+1) log_2(k+2) = Theta(r^2 log r),
  h(r) = 11 + r + sum_{k=2}^{r} g(k) (k+2)^{k+1} = 2^{Theta(r^2 log r)},
  N(r) <= r + h(r) <= 2^{O(r^2 log r)}.
```

This is the claimed closed form: explicit, computable, and a function of `r`
alone. It improves the companion bound `2^{2^{O(r)}}` to `2^{O(r^2 log r)}`.

## 4. Numerical verification

`islands/01-recurrence/scratch/verify_closed_form_sharp.py` checks the
claim against the validated solver (the
recurrence of section 0, implemented in C++ and cross-checked against the
published tables):

- exact big-integer evaluation for `r <= 12` (`g(12)` is a 74-digit integer):
  `N(r) <= r + h(r)` holds for every row, live and stale;
- log-space evaluation for `r <= 60`: the same inequality holds throughout,
  with `log_2 g(r) ~ (r^2/2) log_2 r` confirmed.

## 5. What this does and does not claim

It claims a **closed-form computable bound** `N(r) <= 2^{O(r^2 log r)}`,
obtained by a finite-state pigeonhole plus a value bound, with the lcm
recursion read linearly (the phase in the state forces the repeated-period to
be a common multiple of `q_r` and `p_r`). It does not claim any polynomial or
linear bound: sharpening to `C·r` remains a separate, much deeper question and
is not addressed here.

## Addendum (2026-10-02, adversarial self-review): two presentation fixes

Neither affects the bound; both make the proof referee-tight.

**1. Lemma A' as written assumes the repeated state exists ("Among the S+1
consecutive states ... two coincide"). For a STALE row the sequence terminates
at `a* = u_r - 1` and states beyond termination do not exist, so the sentence
is literally false there. Fix: split cases. For a live row the states
`S_{A0}, ..., S_{A0+S}` all exist (all `L_a` defined and `>= 1`), and the
pigeonhole applies as written. For a stale row `p_r := 1` by convention, so
`q_{r+1} = lcm(q_r, 1) = q_r <= q_r (m_r+1)^{m_r}` is trivially true and Lemma
A' holds without any pigeonhole. (The same case-split already appears in C0024
section 4's stale paragraph.)

**2. Lemma C' says "Since h(r-1) >= 12 > r+1, the max is h(r-1)". The
inequality 12 > r+1 is false for r >= 12. What is needed and true:
`h(r-1) >= r+1` for all r >= 2. Since `h(r) = 1 + h(r-1) + g(r)(r+2)^{r+1}`
implies `h(r) >= h(r-1) + 1`, induction gives `h(r-1) >= h(1) + (r-2) = r + 10
>= r+1`. Hence `max(t_r, m_r) <= max(h(r-1), r+1) = h(r-1)` and the argument
runs unchanged.

**3. Dependency note.** Input 2's (ii)-(iii) use `M = m_r` as the bound on the
current row's own `L`-values. That step is Zeilberger's Lemma Bounded applied
to the instant-winner sets: `max W_r(a) <= m_r - 1` (all `W` singletons are
`B_c`-values or `B_c(0)`-values with `c < r`), and `mex(S) <= max(S)+1`
propagates to `L_a <= m_r` for all `a` of the current row. Verified against the
source (zeilberger_chomp_recurrences_chaos.tex, line ~612). Independently,
C0012 alone gives `L_a <= r+1`, and since the closed form only uses
`(m_r+1)^{m_r} <= (r+2)^{r+1}`, the bound `N(r) <= r + h(r)` is unaffected even
if one declines to use Zeilberger's Lemma Bounded.

## Addendum 2 (referee gap, t=0.8 run of 2026-10-02): why p_r | s

The referee flagged "p_r | s" as true but unproved. The missing standard step:

**Lemma (periods form a group).** If a sequence is purely periodic on a tail
with least period p and is also s-periodic there, then p | s.

*Proof.* Let x be periodic on [a, ∞) with least period p and with period s.
For i >= a, x_i = x_{i+g} with g = gcd(p,s): by Bezout g = ap + bs for
integers a,b; iterating the p-periodicity |b| times and the s-periodicity |a|
times (all indices stay >= a since we only move forward by positive multiples
of p or s... careful: Bezout coefficients may be negative). Clean version:
the set T = {t >= 0 : x_i = x_{i+t} for all i >= a} is closed under subtraction
of a smaller element (if t,t' in T with t > t', then x_i = x_{i+t-t'} for all
i >= a: indeed x_{i+t-t'} = x_{i+t} (shift by t' in T) = x_i (shift by t in T)).
A nonempty set of non-negative integers closed under subtraction is generated
by its least element g. Since p, s in T, g | p and g | s. As p is the LEAST
period, g = p, hence p | s. ∎

Applied here: the machine's L-sequence is purely periodic on [a1, ∞) with
least period p_r (p_r is BY DEFINITION the least period of the tail from u_r;
and a suffix of a purely periodic sequence has the same least period — the
tail is the repetition of a cyclic word of length p_r and a suffix is the
repetition of a cyclic shift of it, which has the same least period). Since it
is also s-periodic there (the state cycle), the lemma gives p_r | s. This is
exactly what Lemma A' needs for q_{r+1} = lcm(q_r, p_r) | s.
