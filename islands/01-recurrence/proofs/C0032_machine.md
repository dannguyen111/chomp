# C0032 / C0033 — the merged-trail machine and its determinism onset

This file proves two lemmas about Zeilberger's Fundamental Recurrence that
together re-found the preperiod analysis on a *deterministic machine with an
explicit start time*. Both lemmas are exact algebraic reformulations; nothing
here is conjectural.

Notation (same as proofs/C0024.md). Fix the third row `r`. For `c < r`:

```
  B_c(x)   = f(c+x, c) - (c+x)                  (loser coordinate of row c)
  u_c      = N(c) - c                           (row c preperiod, a-coords)
  p_c      = period of row c (p_c := 1 for stale rows)
  q_r      = lcm{ p_c : c < r }
```

Zeilberger's instant winners at `[r, a, .]` decompose (C0024, Section 1) as

```
  V''_{r,c}(a) = { B_c(a + r - c) }                        (defined values)
  V'_{r,c}(a)  = { B_c(0) - (r-c) - a }  ∩ Z_{>=0}
  W_r(a)       = V''(a) ∪ V'(a),     V''(a) = ⋃_{c<r} V''_{r,c}(a),
                                    V'(a) = ⋃_{c<r} V'_{r,c}(a),
```

and the Fundamental Recurrence is

```
  L_a = mex( W_r(a) ∪ { L_{a-1} - 1, L_{a-2} - 2, ... } ),      (FR)
```

mex over the **non-negative** integers, `L_a = B_r(a)`, `L_a = 0`
terminating the row (stale), all `L_a` defined and `>= 1` for live rows.
Write `dec(X) = { x-1 : x ∈ X, x >= 1 }`.

## C0032 (Lemma M — merged-trail machine)

**Claim.** Define `H_0 := V'(0)` and iterate

```
  k_a = mex( V''(a) ∪ H_a ),      H_{a+1} = dec(H_a) ∪ { k_a - 1 }.    (M)
```

(with the convention that `k_a = 0` terminates). Then `k_a = L_a` and
`H_a = V'(a) ∪ T_a` for all `a`, where `T_a = { L_{a-i} - i : i >= 1 }
∩ Z_{>=0}` is the trail of (FR).

**Proof.** Two independent identities, both one line.

1. `V'(a+1) = dec(V'(a))`. Indeed `V'(a) = { B_c(0)-(r-c)-a : c < r } ∩ Z_{>=0}`
   and `dec` maps the singleton at value `v` to the singleton at `v-1`,
   discarding `v = 0`; that is exactly the `a ↦ a+1` shift of the family.

2. `T_{a+1} = dec(T_a) ∪ { L_a - 1 }` (for `L_a >= 1`; if `L_a = 0` the row
   terminates). Indeed
   `T_{a+1} = { L_{a+1-i} - i : i >= 1 } ∩ Z_{>=0}
            = ( { L_a - 1 } ∪ { L_{a-j} - (j+1) : j >= 1 } ) ∩ Z_{>=0}
            = { L_a - 1 } ∪ dec(T_a)`.

Both families therefore obey the *same* decay rule, so their union
`H_a := V'(a) ∪ T_a` obeys `H_{a+1} = dec(H_a) ∪ { L_a - 1 }`, and (FR)
reads `L_a = mex( V''(a) ∪ V'(a) ∪ T_a ) = mex( V''(a) ∪ H_a )`. With
`H_0 = V'(0) ∪ T_0 = V'(0)` (empty trail at `a = 0`), induction on `a` in (M)
gives `k_a = L_a` at every step. ∎

**Consequences.** (a) The whole row-`r` dynamics is a deterministic machine
driven by the single input sequence `V''(a)`; the `V'` family needs no separate
handling. (b) The state `(τ; H)` with `τ = a mod q_r` is deterministic as soon
as `V''` is `q_r`-periodic; the state space is `q_r · 2^{m_r}` sets `H ⊆
[0, m_r]`, but the *shape* of `H` is heavily constrained (see the attractor
discussion in NOTES.md).

## C0033 (Lemma S — determinism onset)

**Claim.** `V''(a)` is `q_r`-periodic for all `a >= σ_r`, where

```
  σ_r = max_{c<r} N(c) - r =: M_{r-1} - r,      M_{r-1} = max_{c<r} N(c).
```

In particular the machine (M) is autonomous (deterministic given its state and
phase) from `a = max(σ_r, 0)` on, and the L-sequence is generated by a
deterministic finite machine from `a = σ_r` on.

**Proof.** Componentwise. Fix `c < r`. The component `V''_{r,c}(a) =
{ B_c(a + r - c) }` evaluates `B_c` at argument `x = a + r - c`, and `x >=
u_c = N(c) - c` iff `a >= N(c) - r`. On arguments `x >= u_c`, `B_c` is either
`p_c`-periodic (live `c`) or undefined forever (stale `c`); in both cases the
map `a ↦ V''_{r,c}(a)` is `p_c`-periodic on `a >= N(c) - r`. Since `p_c | q_r`,
it is `q_r`-periodic there. Taking the maximum over `c < r` of the thresholds
gives `σ_r = max_{c<r} (N(c) - r) = M_{r-1} - r`. ∎

**Remark (why σ_r, not t_r).** C0024's Lemma P made `W_r` periodic only at
`t_r = max(U_r, r)`, because it waited for the `V'` family to extinguish
(`a >= r`). Lemma M absorbs `V'` into the state, so only `V''` matters for
autonomy, and `V''` goes periodic at `σ_r = M_{r-1} - r`, which is *strictly
earlier*: numerically `σ_r ≈ (√2-1) r ≈ 0.414 r` while `t_r = r`. The observed
preperiod `u_r = N(r) - r ≈ 0.414 r` tracks `σ_r`, not `t_r`; the census gives
`u_r - σ_r = N(r) - max_{c<r} N(c) ∈ [-4, 6]` for all `r <= 50000`
(claim C0034). So the right conjecture is an O(1) convergence bound of the
machine (M) after determinism onset, which would give
`N(r) <= max_{c<r} N(c) + K` and hence `N(r) <= K·r` by a one-line induction.

## Numerical validation

`scratch/machine_validate.py`, against the GROUND_TRUTH solver:

- **V1** machine (M) reproduces `f(r+a,r) - (r+a)` exactly, all rows `r <= 300`,
  all `a` in range, stale rows including their terminating `0`;
- **V2** `V''` is `q_r`-periodic from `a = σ_r` on sample rows (0 failures);
- **V3** `u_r - σ_r <= 4` for `r <= 300`; the 50000-row census gives the range
  `[-4, 6]` (C0034).

Abstract-machine sweeps (`scratch/machine_abstract.py`) show the worst-case
L-transient of (M) over all q-periodic inputs `V ⊆ [0,M]` grows at least like
`~M·q` (12 at `M=4, q=3`), so an O(1) bound is **false for general inputs** and
must use the chomp-specific structure of `V''` and of the state reached at
`σ_r` (the interval attractor; see NOTES.md).
