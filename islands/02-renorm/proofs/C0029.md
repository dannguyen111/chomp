# N(r) <= 2r + 2 for every stale row (hence <= 3r)

## Statement

For every **stale** row `r` (a row with only finitely many P-positions
`[p, q, r]`, `p >= q >= r`), let `c_r` be the value of the row once it is
constant. Then

```
f(c_r, r) = c_r,     N(r) = c_r + 1,     c_r <= 2r + 1,
```

so `N(r) <= 2r + 2`, and `N(r) <= 3r` for every stale `r >= 1`. Here `N(r)` is
`1 +` the last `q` carrying a P-position `[p, q, r]` with `p >= q`. This makes
the stale-row step of Byrnes' periodicity theorem effective, with the computable
bound `K(r) = 2r + 2`.

## Why not the route through the constant-row sequence

A shorter-looking route goes through #G07 section 8.8. That section bounds the
`n`-th smallest constant value by `q_n <= 3n - 1`, and the route then needs the
row carrying `q_n` to be at least `n`. That would follow if constant values
increased with the row, which holds numerically through `r = 50000`. We know of
no proof of it, and #G07 section 8.11 leaves a closely related question about
row minima open. The proof below needs neither 8.8 nor that monotonicity.

## Inputs (all in print)

- **(S2.1) Sheiner, arXiv:2605.23837, Lemma 2.1.** For `q >= r >= 0` there is a
  unique `p = f(q, r) > r` such that either `r < p < q` and `[p, p, r]` is a
  P-position, or `p >= q` and `[p, q, r]` is a P-position. This `f` is the
  project recurrence (MISSION.md section 2; #G07 section 8.1).
- **(S4.2) Sheiner, Lemma 4.2 (row-start propagation).** If `f(p, r) = p`, then
  for every `q` with `r < q < p`, `p` lies in `C(q, r) = {f(q, b) : 0 <= b < r}`.
  Machine-checked in Sheiner's Lean archive.
- **(B8.1) #G07 section 8.1.** `f(q, b) <= q + b + 1` for `q >= b`.

## Lemma 1 (the freeze value is the freeze point)

Let `r` be stale and let `q0` be the least `q >= r` with `f(q, r) <= q`. Then
`f(q0, r) = q0`, `f(q, r) = q0` for all `q >= q0`, and the P-positions
`[p, q, r]` with `p >= q` are exactly those with `r <= q <= q0`.

*Proof.* `q0` exists: otherwise `f(q, r) >= q + 1` for every `q >= r`, and by
(S2.1) each `[f(q, r), q, r]` is a P-position. That makes infinitely many, which
contradicts staleness.

Let `p = f(q0, r) <= q0` and suppose `p < q0`. By (S2.1), `r < p < q0` and
`[p, p, r]` is a P-position. Applying (S2.1) at the pair `(p, r)`, the value
`p` satisfies its second alternative (`p >= p`, `[p, p, r]` a P-position), so by
uniqueness `f(p, r) = p`. But `r < p < q0` and `f(p, r) <= p` contradict the
minimality of `q0`. Hence `p = q0`.

The second branch of the recurrence (`f(q-1, r) < q` gives
`f(q, r) = f(q-1, r)`) then holds at every `q > q0` by induction, so
`f(q, r) = q0` for `q >= q0`. For `r <= q < q0` we have `f(q, r) >= q + 1`,
giving the P-position `[f(q, r), q, r]`. At `q0` the P-position is
`[q0, q0, r]`. For `q > q0`, a P-position `[p, q, r]` with `p >= q` would make
`f(q, r) = p >= q` by uniqueness. But `f(q, r) = q0 < q`, so there is none. ∎

So `N(r) = q0 + 1 = c_r + 1`, where `c_r = q0` is the row's constant value.

## Lemma 2 (`c_r <= 2r + 1`)

*Proof.* If `c_r <= r + 1` we are done, since `r + 1 <= 2r + 1`. Otherwise
`r < r + 1 < c_r`, and `f(c_r, r) = c_r` by Lemma 1. So (S4.2) at `q = r + 1`
gives some `b < r` with `f(r + 1, b) = c_r`. By (B8.1),

```
c_r = f(r+1, b) <= (r + 1) + b + 1 <= (r + 1) + (r - 1) + 1 = 2r + 1.  ∎
```

## The bound

`N(r) = c_r + 1 <= 2r + 2`. For `r >= 2`, `2r + 2 <= 3r`. For `r = 1`, the
recurrence gives `f(1,1) = 3` and `f(q,1) = 2` for `q >= 2`. So `c_1 = 2` and
`N(1) = 3 = 3·1`. The bound is explicit and computable, and it never appeals to
Byrnes' non-effective periodicity.

## Verification (numerical, evidence not proof)

- A 400 x 400 table built from the recurrence alone (no solver), 117 stale rows:
  `f(q0, r) = q0` every time, (S4.2) holds at every `r < q < c_r`, and
  `c_r <= 2r + 1` holds. `max c_r / r = 2.0`, at `r = 1`.
- `census_20000.tsv`, all 11716 stale rows: `N = dconst + 1` every time,
  `dconst <= 2r + 1` every time, `max N / r = 3.0` at `r = 1`.
- The ratio `N(r) / r` tends to `sqrt(2)` numerically, so `2r + 2` is loose by
  a constant factor. For effectivity, any computable bound will do.
