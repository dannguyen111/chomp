# C0029 — N(r) <= 3r for every stale row, closing (B1)

## Statement

For every **stale** row `r` (equivalently `r in A029902`, the rows with only
finitely many P-positions), every P-position `(p, q, r)` has

```
q  <=  3r
```

equivalently `N(r) <= 3r`, where `N(r)` is the least `q0` with `f(q,r)-q`
exactly periodic for all `q >= q0` (for a stale row this is `1 +` the last `q`
carrying a genuine P-position). This closes gap **(B1)** of
`GROUND_TRUTH/byrnes_audit.md` with `K(r) = 3r`, using published prior art.

## Ingredients (all in print or already logged)

1. **BHMS §8.8** (Brouwer, Horvath, Molnar-Saska, Szabo, "On Three-Rowed
   Chomp", INTEGERS 5 (2005) #G07, section 8.8) proves:

   > **Claim.** `q_n <= 3n - 1`

   where `q_n = A029901(n)` is the `n`-th constant-row value, i.e. the value
   (and starting `q`) of the `n`-th constant ("stale") row: the pair
   `(q_n, r_n)` satisfies `f(q_n, r_n) = q_n`. The proof is a contradiction
   argument using the diagonal sequence `d_n = f(n,n)` and the fact that every
   integer not on the diagonal is the value of a constant row.

2. **A029902 is increasing.** `r_n = A029902(n)` is the `n`-th constant-row
   *index* (second coordinate). As a strictly increasing sequence of positive
   integers, `r_n >= n` for all `n >= 1`.

3. **`N(r) = q_n + 1` for a stale row** (claim C0005, verified for all 29289
   stale rows to `r = 50000`). For a stale row `r = r_n`, the last genuine
   P-position is at `q = q_n` (the start of the constant row), so
   `N(r_n) = q_n + 1`.

## The chain

```
N(r_n)  =  q_n + 1                          (ingredient 3)
        <=  (3n - 1) + 1  =  3n             (ingredient 1)
        <=  3 r_n                            (ingredient 2: r_n >= n)
```

Hence `N(r) <= 3r` for every stale row `r`. Equality is attained only at
`r = 1` (`q_1 = 2`, `N(1) = 3 = 3·1`).

## Why this closes (B1)

`GROUND_TRUTH/byrnes_audit.md` section 3 defines:

> **(B1)** Exhibit a computable `K` such that for every `r` whose row is stale,
> every P-position `(p,q,r)` has `q <= K(r)`. This is `W(A,0)` and it is the
> only thing Byrnes' proof does not supply.

The audit's own section 3 says "Anything computable will do — `3r`, `r^2`,
`2^r`." The present claim supplies exactly `K(r) = 3r`, and moreover the
ingredient `q_n <= 3n-1` is **already proved in print** (BHMS §8.8), not merely
conjectured. The audit did not notice that BHMS §8.8 already provides the needed
input.

## Verification (numerical, evidence not proof)

Over all 29289 stale rows with `1 <= r <= 50000` (index `n` from 1):

- `q_n <= 3n - 1`: 0 violations.
- `N(r) = q_n + 1`: 0 exceptions (C0005).
- `r_n >= n`: 0 violations.
- `N(r) <= 3r`: 0 violations; equality only at `r = 1` (`N = 3`).

The bound is far from tight: the maximum of `N(r)/r` over stale rows is 3.0 at
`r = 1`, and the ratio tends to `sqrt(2) = 1.4142...` (C0003).

## Status and novelty

The **bound** `q_n <= 3n-1` is prior art (BHMS §8.8, 2005). The **chain** to
`N(r) <= 3r` for stale rows — and hence the closure of (B1) — is the new
contribution. It is an observation/lemma assembled from published results plus
the logged identity C0005. Novelty check deferred to the referee.
